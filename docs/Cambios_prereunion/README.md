# Cambios prereunión (asesora)

Carpeta viva de lo que se cambia en producto **antes de hablar con la asesora** (Lourdes / Monfort Partners u otra persona de RRHH).

## Cómo usarla

- Cada cambio de código o de criterio de producto se anota aquí (nueva entrada o ampliación del changelog).
- No es el guion de defensa del TFM ni un ensayo de pitch teatral.
- El objetivo de la reunión es **escuchar y contrastar** con alguien de selección/RRHH: qué echan en falta, qué entienden en pantalla, qué no comprarían.

## Qué no hacemos a partir de ahora

- No ensayar ni presentar el **guion de demo de 3 minutos** (antiguo punto **1E**) como si fuera una defensa.
- No preparar un “show” de diapositivas para esta reunión.
- Sí: tener la web en un estado creíble, datos reales en Supabase, y poder abrir pantallas concretas si la conversación lo pide.
